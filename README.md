### Enllaç amb els commands

git --version

git status 
git commit -m "Name"
git branch -M main
Ctrol + s (save)
git remote add origin (URL git hub)
git remote -v

### Taula

- git init = Iniciar el directori en un nou projecte
- git status = Mostrar l'estat o el lloc en el que estas
- git --version = Mostra la versió en la que estas treballant
- git push = Pujar la versió del archiu a github de manera actualitzada
- git remote add origin (URL github)=incules el teu directori de github
